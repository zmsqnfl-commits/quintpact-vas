VAS 2.9.0 — 처음에는 이것만 하세요
====================================

채팅으로 시작하기 (VAS 2.9.0)
-------------------------
프로젝트 지침을 읽는 코딩 AI에서 이 폴더를 열고 "예약 관리 앱 만들어줘"처럼 요청하세요.
AI가 새 앱·기존 앱·VAS 개발을 구분하고 실제 작업 폴더와 필요한 조건을 정리합니다.
Python 3.10+가 있는 코딩 호스트에서는 설정 요약을 이 PC에 저장하고 다음 대화에서 이어갑니다.
작업 폴더는 PC 전용 연결 정보에만 저장하며 공유 설정이나 웹 응답에는 넣지 않습니다.
"이 작업의 디자인 화면 열어줘"라고 하면 저장한 작업에 연결된 로컬 디자인 스튜디오를 엽니다.
화면에서 선택한 뒤 "대화 설정에 저장"을 눌러야 같은 작업에 반영됩니다. 샘플 보기만으로는 저장되지 않습니다.
AI는 다음 요청·구현·위임·저장 전에 최신 설정을 읽습니다. 화면 저장만으로 AI가 자동 실행되지는 않습니다.
편집 전 화면은 최신 설정을 반영하고, 저장 전 초안이 있으면 변경 충돌을 표시하며 초안을 유지합니다.
기존 앱은 디자인 유지가 기본입니다. 바꾸려면 부분 수정 범위나 전체 리디자인을 직접 선택하세요.
독립 HTML·GitHub Pages에서는 로컬 대화 설정에 연결하지 않습니다. 자세한 연결법은 docs/CHAT-DESIGN.md에 있습니다.
"이 설정으로 만들어줘"라고 하면 AI가 최신 설정으로 인계를 준비하고 실제 앱 원본을 읽어 구현·검증합니다.
실행 준비에는 작업 요청과 필수 완료조건이 필요합니다. 요청에서 명확한 조건은 AI가 정리합니다.
위임 도구가 있고 독립 작업이 유용하면 역할을 맡기고, 없으면 주 실행자가 순서대로 수행합니다.
설정이 바뀌면 이전 결과를 그대로 쓰지 않고 최신 지시와 대조합니다.
실제 테스트 통과 보고와 VAS 평가·사용자 직접 확인은 구분합니다. 자세한 절차는 docs/CHAT-EXECUTION.md에 있습니다.
제한된 Windows 호스트가 전용 저장소를 읽지 못하면 접근 실패를 알리며 권한을 자동 변경하지 않습니다.
VAS 2.9.0은 대화형 시작, PC 설정 저장, 디자인 연결, 구현 준비와 결과 평가를 제공합니다.
자세한 사용법은 docs/CHAT-START.md에 있습니다.

화면으로 설정하기
-----------------
1) 받은 ZIP을 새 폴더에 모두 풉니다.
2) Run-VAS-System.bat를 더블클릭합니다.
3) 열린 화면에서 시작 방식을 고릅니다.

새 프로그램을 만들 때
----------------------
`새 프로젝트 만들기` → 요구사항·완료조건 작성 → 디자인 선택 → 최종 내용 확인 → 프롬프트 복사
기존 초안이 있으면 먼저 복원하거나 삭제합니다. 선택하기 전에는 기존 초안을 덮어쓰지 않습니다.

기존 프로그램을 고칠 때
------------------------
`기존 프로그램 AI로 연결` → 폴더 위치 선택 → 작업·완료조건 작성 → 디자인 변경 범위 확인 → 프롬프트 복사
기본값은 `기존 디자인 유지`입니다. 필요한 기능은 기존 컴포넌트와 규칙을 재사용합니다.
디자인을 바꾸려면 `부분 디자인 수정` 또는 `전체 리디자인`을 직접 선택하세요.
부분 수정에서는 바꿀 화면·요소·속성을 적습니다. 데이터 삭제나 다른 기능 변경 권한은 포함되지 않습니다.
내용을 수정한 뒤에는 `전달 내용 다시 준비`로 최신 프롬프트를 확인하세요.

예: 기존 프로그램에 CSV 내보내기 추가
-------------------------------------
작업: "주문 목록에 CSV 내보내기 버튼을 추가해 주세요."
디자인: `기존 디자인 유지`
완료조건: "내보낸 CSV의 한글이 깨지지 않고 주문 합계가 화면과 일치한다." / 수동 확인
코딩 도구가 기존 원본을 읽고 버튼을 구현한 다음 실제 CSV를 열어 확인합니다.

완료조건과 READY
----------------
기존 화면 인계에서는 완료조건이 선택입니다. 대화형 실행 준비에는 필수조건이 하나 이상 필요합니다.
결과별로 한 조건씩 적고 자동 검사·수동 확인·정적 검토를 고릅니다.
조건은 최대 20개, 각 500자까지입니다. 추가한 빈 조건은 내용을 적거나 삭제하세요.
READY는 `인계 자료 준비 완료`이며 개발 작업의 완료나 검사 통과를 뜻하지 않습니다.
완료조건이 없거나 확인하지 않은 결과를 자동으로 완료했다고 간주하지 않습니다.

디자인 참고
------------
인계에는 버전을 식별할 수 있는 기본 스타일 참조, 확정 토큰과 적용 범위를 담습니다.
사용자가 세부 값을 바꿨다면 기본 샘플보다 확정 토큰을 따릅니다. 참조를 열지 못하면 미확인으로 남깁니다.
기존 디자인 유지에서는 새 스타일 적용 지시를 전달하지 않습니다.

AI에게 전달한 다음
----------------
1. Codex, Claude, Antigravity 같은 코딩 도구를 엽니다.
2. 새 프로젝트는 빈 폴더, 기존 프로그램은 원본 폴더를 작업 폴더로 엽니다.
3. VAS가 복사해 준 프롬프트를 붙여넣습니다.
4. 설정 보관이 필요하면 VAS-AI-HANDOFF.json도 프로젝트 최상위 폴더에 저장합니다.
5. VAS는 닫아도 됩니다. 코딩 도구가 실제 파일을 먼저 읽고 수정·테스트합니다.

다시 설정하려면
---------------
시작 방식을 다시 고르거나 인계 준비 화면의 `작업 기억 설정`에서 기억을 켜거나 끄고 중지·삭제할 수 있습니다.
`사용 방법`을 누르면 이 순서를 다시 볼 수 있습니다.

꼭 알아둘 점
------------
- VAS는 폴더 위치만 프롬프트에 넣고 내부 구조·기술 스택은 분석하지 않습니다.
- JSON에는 절대 경로, 비밀번호, API 키, 연락처, 작업 기억 원본을 넣지 않습니다.
- 실제 프로젝트 분석은 Codex·Claude·Antigravity가 열린 원본 폴더에서 수행합니다.
