# Kinetic Type

- Identity: a bold culture studio in electric purple, warm white and acid yellow, led by expressive typography and controlled movement.
- Composition: a compact italic wordmark above an oversized staggered LESS / ORDINARY. / MORE YOU. statement, a yellow action, a narrow moving type band and a white reversed project index.
- Typography: a strong condensed italic display such as Anton with deliberate line-by-line sizing and offsets; Bricolage Grotesque or a similar expressive sans for support. Use native text, not a screenshot of lettering.
- Artwork: the headline is the hero artwork. One large asterisk or typographic seal may balance the empty corner; do not substitute a stock photo or generic gradient blob.
- Detail: dominant purple canvas, almost no rounded cards, thin dividers and an indexed work list. Keep only one clearly dominant action above the list.
- Responsive: scale and offset each headline line inside the viewport, keep punctuation visible and wrap project metadata beneath names on narrow screens. Check both Korean replacement copy and the sample Latin display.
- Motion: the type band loops slowly with a visible pause control; respect prefers-reduced-motion. Navigation and project details remain usable when static. Check actual text bounds, focus, contrast and selected tokens at 320px and desktop.
