# Kinetic Type

- Scope: borrow visual elements only. Features, routes, data and actions come from the user request and existing app, not this sample. Add sample functionality only when explicitly requested; preserve required functionality even when the sample lacks it.
- Identity: electric purple, warm white and acid yellow, led by expressive typography and controlled movement. The culture-studio sample does not define the app's subject.
- Composition: use deliberate staggered heading scale and offsets, one prominent requested action and contrasting horizontal emphasis. A moving band or indexed list is optional when useful; do not import the sample's slogans or project index.
- Typography: strong condensed italic display such as Anton, with deliberate line sizing; Bricolage Grotesque or similar expressive sans support. Use native text with the user's actual wording, not screenshots of letters.
- Artwork: typography can be the focal image. A simple abstract asterisk may balance space; ornamental work must not crowd the requested controls and data.
- Detail: dominant purple canvas, sparse containers and thin dividers. Keep one clearly dominant action only when the actual workflow has one, and retain all required secondary controls.
- Responsive: fit each heading line inside the viewport, preserve punctuation and wrap actual secondary content. Check Korean text as well as Latin without copying sample display text.
- Motion: optional type movement needs a visible pause and reduced-motion fallback. Required content remains usable when static. Check text bounds, focus, contrast and selected tokens at 320px and desktop.
