# Architecture Editorial

- Scope: borrow visual elements only. Features, routes, data and actions come from the user request and existing app, not this sample. Add sample functionality only when explicitly requested; preserve required functionality even when the sample lacks it.
- Identity: warm gray canvas, near-black typography and expressive but usable editorial art direction. The sample's architecture business is illustrative, not the requested product.
- Composition: adapt the large-heading/small-introduction contrast, open grid and fine-rule rhythm to the actual task. Use a photographic focal point only when relevant; do not add a portfolio index or inquiry form from the sample.
- Typography: strong grotesk display scale, tight tracking and quiet UI text. Preserve confirmed fonts and Korean legibility; mobile headings wrap without cropping words.
- Media: use original subject-relevant photography with an intentional crop. The courtyard image belongs to the fictional FORM / FIELD sample; do not present it as the user's project or require architecture imagery.
- Detail: sharp geometry, fine horizontal rules, generous margins and small secondary captions. User-customized radius, spacing and colour tokens override defaults.
- Interaction: apply clear focus, validation and feedback to controls the task actually needs. No sample section or local demo interaction authorizes a new form, route or service.
- Responsive: stack asymmetric regions in logical reading order and preserve required controls and content at 320px. Compare actual desktop/mobile hierarchy and spacing with the visual reference.
