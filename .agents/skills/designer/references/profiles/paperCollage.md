# Paper Collage

- Scope: borrow visual elements only. Features, routes, data and actions come from the user request and existing app, not this sample. Add sample functionality only when explicitly requested; preserve required functionality even when the sample lacks it.
- Identity: blush paper, chocolate serif text and tangible analogue image treatment. Borrow layered warmth without turning the app into a journal.
- Composition: combine a clear reading grid with restrained asymmetry and optional overlapping prints. Fit actual requested content; do not add issue entries, article indexes or journal navigation from the sample.
- Typography: DM Serif Display or a compatible literary serif, generous body leading, small secondary labels and handwritten accents only where legible. Keep functional labels clear.
- Media: use relevant images as rotated ivory prints with paper tape and soft natural shadows. Sample wildflowers, architecture and coastline are not required subjects. All actual headings, controls and text remain native HTML.
- Detail: subtle grain, bounded overlap and modest underlined or solid actions. Keep paragraphs off photographs and do not flatten the whole screen into a mockup image.
- Responsive: stack overlapping prints when needed and preserve the actual content order with fine separators. Maintain proportions and avoid rotated-image overflow at 320px.
- Behaviour: implement only requested actions. Motion is static or minimal; verify image loading where used, focus, contrast and confirmed tokens on desktop and mobile.
