# Minimalist Utility

- Composition: use a quiet navigation row, breadcrumb, a document-width reading column, title and summary, then ordered sections or notes. Keep supporting tools close to the content they affect.
- Hierarchy: body at the confirmed base size with 1.7 line height, title at 2-2.75 times, subheadings at 1.25-1.5 times, and metadata at 0.8-0.875 times. Limit prose to about 60-72 characters per line.
- Rhythm: use the confirmed padding token between sections and half that for connected rows. Structure lists with alignment and subtle rules; do not put every paragraph or metric in a separate card.
- Details: use descriptive document names, dates, small indices and restrained icons. Give selected navigation, links and important actions a distinct emphasis without making all text bold.
- Controls: keep search, editing and disclosure behavior explicit. Use native semantics and visible focus; expose useful empty, saved and error states where the user is working.
- Responsive: collapse navigation to a compact menu and keep the reading column fluid with 16-24px side gutters. Wrap long names and move secondary metadata to a new line.
- Preserve confirmed colors, radii, framework and existing font assets. Check reading comfort, text selection, keyboard actions and 320/390px plus desktop renders.
