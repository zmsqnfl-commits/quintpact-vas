# Editorial Motion

- Composition: a compact masthead, a 7:5 headline/visual split, then an indexed list of selected work. Use this structure for editorial or portfolio content; retain task-focused layouts for operational screens.
- Hierarchy: one dominant headline at 3-4 times body size, section titles at 1.5 times, and quiet metadata at 0.8 times. Use short Korean lines, word-break: keep-all, and 1.2 heading / 1.7 body line heights.
- Rhythm: use the confirmed spacing token as one unit; allow 2 units between sections and half a unit within related content. Align text and imagery to one grid instead of framing every block.
- Focal point: use one relevant photograph, illustration, or designed typographic study. Preserve image aspect ratios; do not replace every image with an empty colored rectangle.
- Details: pair project names with categories and small indices, use fine section rules, and reserve the primary fill for the main action. Use real content rather than invented popularity metrics.
- Responsive: collapse the split into headline then visual below 700px; reduce display type to 2-2.75 times body size and move row metadata below titles. Prevent long Korean titles from clipping.
- Motion: a single short reveal or restrained hover is sufficient; respect prefers-reduced-motion and keep reading/navigation immediately available.
- Confirm tokens and references first. Verify hierarchy, image crop, row alignment, keyboard focus and 320/390px plus desktop layouts in the browser; fix differences before handoff.
