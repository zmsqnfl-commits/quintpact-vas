# Aurora Glass

- Scope: borrow visual elements only. Features, routes, data and actions come from the user request and existing app, not this sample. Add sample functionality only when explicitly requested; preserve required functionality even when the sample lacks it.
- Identity: midnight tones lit by cyan and violet aurora, with restrained translucent surfaces. Depth and luminous material are the visual focus, not a requirement to build a workspace.
- Composition: use an atmospheric background and offset frosted surfaces for the requested content. Keep a clear dominant region and visible light between surfaces; add navigation only where the actual app needs it.
- Typography: Space Grotesk or a comparable geometric sans with Korean system fallback. Contrast a larger light-to-medium heading with crisp labels and readable body text.
- Material: one atmospheric image behind glass, hairline translucent edges, an inner highlight and backdrop blur. Provide an opaque dark fallback; check text contrast against the composed background, not just the token swatch.
- Media: keep the text-bearing area dark and quiet; use cyan-violet light and reflected liquid away from reading paths. Never flatten the interface into an image.
- Responsive: stack offset regions when content becomes cramped. Preserve readable padding and the actual app's navigation; a sample dock is not a required feature. Test 320px and desktop.
- Behaviour: required actions keep their own meanings and feedback. Ambient motion is optional, slow and paused for reduced motion. Verify text contrast and light/glass separation with confirmed tokens.
