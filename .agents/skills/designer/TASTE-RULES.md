# VAS 디자인 규칙

사용자 요구와 확정 토큰을 먼저 적용한다. 프로필별 구체 규칙은 `references/profiles/`에 있다.
- 브랜드 색·폰트·대칭·카드·모션은 과제에 맞게 선택한다. 보라색이나 가운데 정렬을 일괄 금지하지 않는다.
- 명확한 정보 계층, 실제 콘텐츠, 키보드 포커스, 읽기 가능한 대비, 반응형을 확인한다.
- VAS 자체는 외부 CDN 없이 시스템 폰트·Vanilla를 사용한다. 생성 대상 프로그램의 기술 제약으로 전파하지 않는다.
- 원본 taste-skills 자료는 선택적 참고다. 강제 라이브러리, 가상 도구 실행, 무작위 설계 지시보다 사용자 요구와 검증 가능한 결과를 우선한다.
