# 개발 흐름

1. 주 실행자: 실제 원본·규칙·요청을 읽고 적용 위치와 완료 조건을 정한다.
2. 복잡한 구조 변경만 Architect와 ultra-plan으로 검토한다. UI 변경에는 designer 스킬을 읽는다.
3. 구현자는 소스와 관련 테스트를 수정하고 화면·동작을 검증한다.
4. 독립 검토가 필요하고 호출 도구가 있으면 검토자에게 diff·요구사항·디자인·검증 증거를 전달한다.
5. 실패와 디자인 차이를 수정한 뒤 관련 검사를 다시 실행한다.
6. 릴리스 전 Python·브라우저·패키지 검증을 수행하고 docs/log.md에 결과를 기록한다.

역할 명칭을 순서대로 말하는 것만으로 별도 에이전트가 실행되지는 않는다. 호출·회수는 호스트의 실제 기능을 사용한다.
VAS는 다른 사용자 프로젝트를 복사·실행하지 않으며, 생성 대상 작업은 사용자가 연 코딩 도구의 실제 폴더에서 수행한다.
