# /migration-cycle

기존 프로그램을 VAS에 안전하게 연결하는 흐름입니다.

1. 사용자가 VAS에서 원래 프로젝트 폴더를 선택합니다.
2. VAS는 폴더 위치만 받으며 내부 파일이나 구조·스택을 분석하지 않습니다.
3. 사용자가 작업 내용과 디자인을 확인합니다.
4. VAS가 붙여넣을 프롬프트를 만듭니다. `VAS-AI-HANDOFF.json` 저장은 선택입니다.
5. 사용자가 Codex·Claude·Antigravity에서 원래 폴더를 열고 프롬프트를 붙여넣습니다.
6. 코딩 도구가 RBG 규칙에 따라 실제 원본·규칙·진입점을 먼저 읽고 계획·구현·검증을 수행합니다.

기존 복사·등록·롤백 모듈은 호환용 내부 기능으로만 남깁니다. VAS 기본 화면은 원본을 실행·수정·삭제하지 않습니다.
