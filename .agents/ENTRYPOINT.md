# VAS 대화 시작

이 폴더는 VAS 도구입니다. 폴더를 열었다는 이유만으로 VAS 소스를 수정하지 않습니다.
첫 요청에서는 아래에 포함된 시작 절차에 따라 요청과 실제 작업 대상을 구분합니다.
시작 절차의 원본은 `.agents/BOOTSTRAP.md`입니다. 이 파일에 같은 내용이 포함돼 있으면 다시 읽을 필요가 없습니다.
사용자에게 지침 파일 읽기, BAT 실행, 폼 작성, 프롬프트 복사를 먼저 요구하지 않습니다.

- 새 앱 제작: 대화에서 요구와 작업 폴더를 정리합니다.
- 기존 앱 수정: 대상 폴더의 원본과 규칙을 확인하고 기존 디자인을 기본으로 유지합니다.
- VAS 자체 개발: 사용자가 VAS 제품 수정을 요청한 경우에만 `.agents/DEVELOPMENT.md`를 적용합니다.
- 위임받은 작업: 전달된 목적·대상·범위를 이어받고 시작 질문을 반복하지 않습니다.

불분명한 대상만 짧게 질문합니다. 이미 정해진 내용과 승인된 범위는 다시 묻지 않습니다.
