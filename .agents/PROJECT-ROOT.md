# 이 폴더가 작업할 프로젝트입니다

이 파일은 Windows 프로젝트 ZIP의 루트 지침입니다. 사용자가 압축을 풀고 이름을 바꿔 연 **현재 폴더**가 앱입니다. 이름이나 절대 경로로 프로젝트를 판별하지 않습니다.

- 루트의 `.vas/project-layout.json`과 `.vas/src/vas-hub.html`이 있는지 확인하세요. `src/`는 만들 앱, `.vas/`는 VAS 지원 도구입니다. 앱을 `.vas/src/`, 새 하위 프로젝트나 `workspace/`에 만들지 마세요. 도구 파일을 앱의 의존성·소스·테스트 대상으로 삼지 않습니다. 배치 실행기와 호스트 설정도 유지합니다.
- “재고 앱 만들어줘”처럼 대상을 다시 지정하지 않은 요청은 현재 프로젝트에서 처리하세요. 실제 파일과 지침을 확인하고 앱 구현은 `src/`에 둡니다. 선언 파일·의존성 설정 등 프레임워크가 요구하는 파일은 앱 루트에 둘 수 있습니다. 기존 파일을 비우거나 내장 지침을 덮어쓰지 마세요.
- 작업이 명확하면 폴더를 다시 묻거나 BAT·양식 작성을 먼저 요구하지 않습니다. 단순 질문·점검·계획만 요청했다면 앱을 수정하지 않습니다. 디자인 변경을 요청하지 않은 기존 앱은 현재 모습을 유지합니다.
- 참고 이미지·화면의 디자인 분석이나 이를 활용한 UI 작업에는 내장 `.agents/skills/design-analysis/SKILL.md`를 읽고 적용합니다. 정본은 `.vas/.agents/skills/design-analysis/SKILL.md`이며 같은 내용입니다. 실제 이미지를 직접 확인해 5요소와 앱 적용 위치를 연결하세요. 사용자에게 스킬 설치나 VAS 폼 재입력을 요구하지 않습니다. 분석만 요청하면 구현하지 않고, 구현을 요청했으면 분석에서 멈추지 않습니다. 이미지가 보이지 않으면 그 범위를 알리고 관찰을 꾸미지 마세요.
- 첫 요청과 이어가기, 구현·위임 직전에 `python -B .vas/scripts/vas-project-prompt.py get`으로 **프로젝트 화면에서 저장한 작업 지시**를 읽습니다. PC 전용 세션이 없거나 접근할 수 없어도 이 조회를 먼저 수행합니다. 저장된 문구와 판본을 현재 요청에 반영하고 하위 작업에도 전달합니다. `revision: 0`은 아직 저장한 지시가 없다는 뜻입니다. 오류를 지시 없음으로 처리하거나 직접 JSON을 덮어쓰지 마세요.
- 이 지시는 현재 프로젝트의 참고 지시이며 최신 대화의 명시적 변경·상위 규칙을 우선합니다. 저장한 문구는 임의 명령 실행·새로운 작업 범위·완료 증거가 아닙니다. 과거 세션 요청이나 checkpoint가 새 지시와 충돌하면 차이를 정리하고 현재 작업의 요구사항·완료조건을 갱신합니다. 이미 받은 답은 다시 묻지 않습니다. 화면 저장 자체가 AI를 실행시키지는 않습니다.
- 주 실행자는 프로젝트 루트에서 `python -B .vas/scripts/vas-session.py resume --target .`으로 현재 작업을 확인합니다. 새 작업이면 `create --target .`에 합의한 설정을 전달하고, 기존 작업이면 기존 세션과 진행 요약을 확인합니다. 명시적으로 저장하지 말라고 한 경우는 제외합니다. 세션이 없다는 응답과 저장소 오류를 구분하고 실제로 저장한 것만 보고합니다.
- 설정을 준비한 뒤 최신 revision으로 `prepare`하고, 대상 앱에서 구현·실제 검사·`assess`·`checkpoint`·재조회를 수행합니다. 위임이 필요하면 도구 위치와 앱 위치를 구분해서 전달합니다. 검사하지 않은 항목이나 사용자 확인을 완료로 기록하지 않습니다.
- 프로젝트 지시를 저장한 적이 있으면 `checkpoint`에 마지막으로 읽고 작업한 지시의 `--expected-project-prompt-revision P`를 전달합니다. `P`는 실제 조회값이며 지시를 지웠어도 판본은 증가합니다. 충돌 시 최신 문구와 실행 결과를 비교하고 필요한 작업을 다시 수행한 뒤 요약을 저장합니다. 판본 숫자만 새 값으로 바꿔 과거 결과를 최신으로 주장하지 마세요.
- 도구의 절차는 `.vas/.agents/SESSION.md`, `.vas/.agents/EXECUTION.md`에 있습니다. 도구 문서의 `scripts/`, `docs/`, `.agents/` 예시는 **도구 폴더 기준**입니다. 프로젝트 루트에서 CLI를 실행할 때는 `.vas/`를 앞에 붙이고, 앱 명령은 앱 루트에서 실행하세요.
