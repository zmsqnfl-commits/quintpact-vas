# VAS 2.10.0 공통 컨텍스트

VAS는 코딩 AI가 요구사항·범위·완료조건·진행 상태를 이어받아 구현·검증·후속 작업을 진행하도록 돕는 로컬 도구다. 디자인은 필요한 작업에서 선택하는 설정이다.
현재 폴더는 VAS 본체이며, 사용자가 만들거나 수정할 앱의 폴더와 구분한다.

- 첫 요청은 `.agents/BOOTSTRAP.md`에 따라 새 앱·기존 앱·VAS 자체 개발로 구분한다.
- VAS 자체 개발에만 `.agents/DEVELOPMENT.md`의 개발 규칙을 적용한다.
- 실제 구현·검증과 역할 위임은 `.agents/HANDOFF-WORKFLOW.md`를 따른다.
- 위임받은 대상과 작업 범위가 있으면 시작 질문을 반복하지 않는다.
- 참고 질문과 구현을 막는 `blockingQuestions`를 구분한다. 미해결 차단 질문은 먼저 정리하고 답한 내용은 최신 설정에 반영한다.
- 사용자 앱의 설정 저장·재개는 `.agents/SESSION.md`의 로컬 CLI로 처리한다. 명시적으로 연결한 로컬 디자인 화면은 같은 저장소를 사용한다. 화면 저장이 AI를 깨우지는 않으므로 다음 요청·구현·위임·저장 전에 최신 설정을 다시 읽는다. 저장 정보는 실행 권한이나 완료 증거가 아니다.
- 진행 요약을 읽은 뒤 실제 원본·diff·검사 근거를 대조한다. 실제 작업 전후에 범위·호스트 반환·선택 파일 관찰을 기록하며 미회수·실패·범위 위반을 성공한 검사로 지우지 않는다.
- `assess.followUp`의 전체 행동에서 실제 남은 문제와 관련 검사만 이어간다. 구간 끝에는 최신 `resume` → `checkpoint` → 재조회로 진행·다음 행동을 저장한다. 파일 표본·호스트 보고·VAS 평가·사용자 확인은 구분하며 자동 조건만 남김없이 충족됐으면 새 수동 확인을 만들지 않는다.
- UI 설정과 프롬프트 복사 방식은 `docs/HANDOFF.md`, 대화 시작은 `docs/CHAT-START.md`에 설명한다.

사용자 앱에 VAS의 기술 스택·검사 명령을 강제하지 않는다. 기능 제공 여부와 실제 실행 증거를 구분한다.
