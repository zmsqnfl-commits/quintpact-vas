# VAS 제품 개발 규칙

사용자가 VAS 자체 개발을 요청했거나 주 실행자가 VAS 개발 작업을 위임했을 때 적용한다. 사용자 앱 제작·수정에는 그 앱의 지침과 검증 명령을 사용한다.

## 목적

VAS는 새 프로그램과 기존 프로그램의 설정을 `VAS-AI-HANDOFF.json`으로 정리해 코딩 AI에 전달하는 로컬 초기 설정 도구다. 대화형 시작 규칙은 `.agents/BOOTSTRAP.md`에 있다.

## 에이전트 실행

`.agents/HANDOFF-WORKFLOW.md`를 따라 주 실행자가 구현·검증을 책임진다. 실제 호출 도구가 있고 독립 작업이 유용할 때만 역할을 위임한다. 네이티브 정의는 `.codex/agents/`, `.claude/agents/`에 있으며 원본은 `.agents/skills/`이다.

## 기준

- 단일 작업 원본: `src/`, `docs/`, `scripts/`, `tests/`와 에이전트 지침
- 결과물: 인계 v3 프롬프트·JSON
- 배포 생성물: `dist/` (Git 제외)
- VAS 개발 TASK·현재 상태·작업 결과는 별도 `VAS-handoff` 저장소에서 관리하며 제품 원본과 배포본에 넣지 않는다.
- 파일당 500줄 이하, 외부 CDN·원격 폰트 금지
- 기존 프로젝트 복사·등록 모듈은 호환용으로만 유지
- 루트 시작 지침은 `.agents/ENTRYPOINT.md`와 `.agents/BOOTSTRAP.md`에서 생성한다. 변경 후 `npm.cmd run agents:build`와 `npm.cmd run agents:check`를 실행한다.

## 흐름

- 대화 시작: 요청과 대상 구분 → 누락 정보 확인 → 해당 작업 진행
- UI 새 작업: 시작 → 요구사항·완료조건 → 디자인 → 인계 v3 → 코딩 도구
- UI 기존 작업: 폴더 위치 → 작업·완료조건 작성 → 디자인 유지(기본) 또는 명시적 변경 범위 → 인계 v3 → 코딩 도구에서 RBG 분석
- 결과 v1 연결과 RAG 검토 모듈은 호환용으로 보존하되 기본 UI에는 표시하지 않음
- 결과 호환 경로는 AI 보고·VAS 평가·사용자 수용을 분리하며 원본 필수조건과 해당 산출물의 직접 확인 없이는 완료로 평가하지 않음
- 작업 기억: 명시적 동의 → 확인한 디자인 선택만 추천 → 완료 화면에서 중지·삭제
- 릴리스: Python → 브라우저 → 패키지 검증

## 안전 규칙

- VAS 런타임은 기존 프로젝트를 실행·수정·삭제하지 않는다. 코딩 호스트가 사용자 요청에 따라 앱을 작업하는 것과 구분한다.
- VAS가 기존 프로젝트의 구조·기술 스택을 추정하지 않는다.
- UI에서 선택한 폴더 위치는 복사 프롬프트에만 넣고 선택 기록 파일을 만들지 않는다. 절대 경로·비밀값·연락처·작업 기억 원본은 JSON에 넣지 않는다.
- 예외: 대화 설정 CLI는 재개에 필요한 절대 대상 경로를 제품 밖의 PC 전용 binding에만 저장한다. 공유 설정·인계 JSON·Git·배포·웹 응답에는 포함하지 않는다. CLI의 로컬 대상 확인 출력과 공개 출력 `export`를 구분한다.
- 동의 전 사용 이벤트를 저장하지 않는다.
- 10회 스트레스 검사는 사용자가 명시한 경우에만 실행한다.

## 완료 기준

`npm.cmd run test:python`, `npm.cmd run test:browser`, `npm.cmd run test:package`가 통과하고 캐시·비밀·사용자 데이터가 Git에 없어야 한다. 지침 파일 검사와 실제 호스트의 첫 응답 검증은 구분해 보고한다.
