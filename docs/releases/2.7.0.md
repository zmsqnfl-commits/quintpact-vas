# VAS 2.7.0

2026-09-07 · 디자인 선택에서 실제 앱 구현·검토까지 확인한 마이너 릴리스입니다.

## 디자인

- Bento Studio, Aurora Glass, Clay Pop, Noir Luxe, Botanical Atelier, Retro Sunset, Swiss Poster, Cyber Deck, Kinetic Type, Paper Collage 컬렉션 10종을 추가했습니다.
- 기존 추천은 Awwwards·Linear·Stripe·Notion 4종으로 선별했습니다. 새 컬렉션과 합쳐 화면에서 14종을 선택하며 이전 28종의 데이터는 저장 설정 호환용으로 유지합니다.
- 건축 스튜디오·프로젝트 보드·구독 서비스·팀 위키를 실제 샘플 사이트로 구현하고 카드에 브라우저 캡처를 표시합니다.
- 선택한 색상·글꼴·간격과 수동 프로필을 샘플 새 창과 AI 인계에 전달합니다. 이미지와 라이선스를 동봉한 글꼴은 로컬 파일로 제공합니다.

## 인계와 에이전트

- 요구사항·참고 URL·확정 토큰·선택 프로필·전체 역할 본문이 누락되거나 잘리는 문제를 수정했습니다.
- 실제 역할 호출을 지원하는 호스트와 일반 하위 에이전트에 역할 지침을 전달하는 경우를 구분합니다. 위임·결과 회수·검토·수정 후 재검증을 기록합니다.
- 검사 명령이 실제 실패 코드를 반환하도록 보완하고 Windows UNC 경로에서 기존 매핑 드라이브를 사용합니다.
- 프롬프트 복사가 기본 동작이며 JSON 저장은 선택입니다. 기존 프로그램의 원본과 기술 스택은 코딩 AI가 직접 확인합니다.

## 실제 검증 앱

- `src/proof-app/index.html`에 Bento 디자인의 Morrow 작업 보드를 포함했습니다.
- 작업 추가·수정·완료·검색·필터·보관·복원·삭제 취소·브라우저 저장·JSON 내보내기를 지원합니다.
- 실제 신청서 → 인계 다운로드 → 디자인·구현·검토 에이전트 실행을 거쳤습니다. 검토에서 발견한 키보드 포커스와 저장 읽기 제한 문제를 수정했습니다.
- 앱은 브라우저 로컬 저장 방식입니다. 서버·계정·AI API나 기기 간 동기화 기능은 포함하지 않습니다.
- 요청·인계 원본·디자인 명세·실행 결과는 `docs/verification/`에 있습니다. 2.6.4에서 생성한 원본 인계는 검증 해시와 함께 당시 내용으로 보존했습니다.

## 업데이트와 배포

- Windows 전체 실행본: `VAS-2.7.0-windows.zip`
- 외부 공유용 독립 신청서: `VAS-Client-Form-2.7.0.zip`
- 파일 검증 자료: `release-manifest.json`, `SHA256SUMS.txt`
- 새 ZIP을 별도 폴더에 전체 압축 해제하고 `Run-VAS-System.bat`를 실행합니다. 기존 폴더와 사용자 데이터는 유지하세요.
- 인계 v3·결과 v1·기존 디자인 저장 키를 유지합니다. 버전업 자체가 사용자 설정을 초기화하지 않습니다.

Python·브라우저·패키지·Windows 압축 해제 실행 검사를 릴리스 절차에 포함합니다. 10회 스트레스 검사는 이번 릴리스에서 실행하지 않습니다.

발행 전 로컬 검증: Python 111개 통과·환경 조건 1개 건너뜀, 브라우저 75개, 패키지 7개, 압축 해제 Windows 실행본 1개, 배포 경계 4개와 원본 해시 검사 통과.
