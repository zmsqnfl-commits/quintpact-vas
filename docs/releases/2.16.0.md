# VAS 2.16.0 — Pick a style by number, and the fonts are back

## One design question, three ways to answer

When nothing has been decided for a new screen, the agent still stops once before building and asks. The answer can now take three forms:

- a site, an image or a description of what you like;
- a style number;
- “알아서 해줘”, which leaves the choice to the agent.

The agent lists six to eight styles that suit the kind of app in the chat, with their numbers, names and one-line descriptions. All 28 styles can be seen as tiles in `ui/style-preview.html`, which opens by double-clicking: it needs no server and loads nothing from the internet.

- Each style has one fixed number. The fourteen public styles are 1–14 and the remaining compatible styles follow as 15–28. The tile preview and `docs/STYLES.md` show the same numbers in every view. `docs/STYLES.md` is generated from `ui/design-presets.js` by `node scripts/build-style-list.cjs` (`npm run styles:build`, checked by `npm run styles:check`).
- The choice is written to the app’s `src/DESIGN.md` by style key, not by number, together with its colours, spacing, corner radius and font. The project memory keeps one line saying the design was decided.
- When `src/DESIGN.md` exists, `start` no longer offers the design question. It returns `designRecorded`, which tells the agent to read the file and not ask again.

The record format in `.agents/skills/design-craft/references/design-record.md` gains a style line, a section for spacing and corners, and a line for the font files copied into the app.

## The six display fonts are back

2.15.0 removed the bundled fonts together with the sample artwork. The artwork was about 24.6 MB of the 26 MB ZIP and stays out; the fonts were about 0.8 MB and return in this release.

- `ui/assets/fonts/` again holds Bricolage Grotesque, DM Serif Display, Space Grotesk, Anton, Caprasimo and Cormorant Garamond, each with its SIL Open Font License file. The Windows ZIP grows from about 1 MB to about 1.8 MB.
- The `@font-face` rules now live once in `ui/design-fonts.css`, which the Design Studio, the sample page and the tile preview all load.
- An app that uses one of these fonts copies the font file and its `-OFL.txt` licence into its own `src/assets/fonts/` and declares it with `@font-face`. It does not depend on a path inside `ui/`. The handoff text, the designer and design-analysis skills and the README say the same.
- These are Latin display fonts. Korean text keeps using the fonts installed on the PC.

## A middle width when the layout changes

The design-craft screen check looks at a wide view, about 390 px and, where possible, 320 px. It now adds a middle width of about 768 px when the number of columns or the placement changes between the wide and the narrow view. Screens whose layout does not change there are not given the extra check.

## Using several AIs

[Using several AIs](../MULTI-AI.md) is a new guide for people who use more than one AI tool. It describes how to give research and drafts to one tool and small checks to another while a single main agent edits the files and writes the project memory, and how to record who drafted and who checked in the `done` summary. VAS does not call other AIs, and the guide is not a required step.

## Moving from 2.15.x

Extract 2.16.0 into a new folder as before. An app that already has a `src/DESIGN.md` keeps it; the next conversation reads it and does not ask about design again.

## Verification

Linux: 1,608 Python tests passed with 144 skipped for Windows PowerShell, 180 browser tests passed with 6 skipped, the package checks (14) and the release-boundary check passed, and `version:check`, `agents:check`, `knowledge:check` and `styles:check` passed. The Windows ZIP built on Linux is 1,849,991 bytes.

New tests cover the bundled fonts and their licences, the single `@font-face` file, the fixed style numbers across the preview’s views at 1440 and 390 px (six fonts loaded, no overflow, no failed requests), the generated style list, `designRecorded` replacing the design question, the middle width rule and the multi-AI guide. A read-only review of the hand-made changes found that the tile preview copied a per-view number instead of the fixed one, that the style order was derived rather than written out, that the licence test counted files without pairing them with fonts, and that the design line in the memory had two formats; all four were fixed and covered by tests.

Not checked here: a real host answering the new question with a number and writing `src/DESIGN.md`, and a new conversation that reads it and does not ask again.
