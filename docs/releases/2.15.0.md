# VAS 2.15.0 — A 1 MB starter and one question about design

## Bundled design assets removed

The starter no longer ships sample artwork, font files or the Morrow proof app.

- `ui/assets/designs/` (ten sample images and four site screenshots), `ui/assets/fonts/` (six fonts with their licenses) and `ui/proof-app/` are removed, together with the 2.7.0 cover image, the proof-app verification records and the two scripts that produced them.
- The Windows ZIP is about 1 MB instead of about 26 MB.
- The Design Studio still offers fourteen choices: ten compositions and four sample sites. Where an image used to sit, a colour block drawn from the palette stands in, and the catalog shows colour strips instead of screenshots. No `img` element and no font file is requested.
- Font names remain in the style sheets as a statement of direction. With no font binary, each preview falls back to the generic family at the end of its stack, so headings can look wider or narrower than before depending on the fonts installed on the PC.

An app that used a bundled font copied from `ui/assets/fonts/` already holds its own copy under its own assets and is not affected. The removed files remain available in the 2.14.0 release and earlier.

## The agent asks once for a reference

When nothing has been decided for a new screen, the agent now stops before building and asks one question: whether the user has a design or a reference site or image in mind. It waits for the answer even when the request is otherwise clear. The rule is a numbered step at the top of the entry instructions and is repeated in the design-craft skill. Other necessary questions go in the same message.

- With a reference, the agent starts from it. A site is opened only when the host can actually open it; otherwise the agent asks for a screenshot rather than imitating something it has not seen.
- Without one, the agent plans the design itself, as before.
- The answer is recorded in the app’s `DESIGN.md` and in the project memory, and the question is not repeated in the same project. Work that preserves an existing design and small edits do not trigger it.

`python -B scripts/vas.py start` carries the question in `nextAction.designQuestion` for a project that has no memory yet.
