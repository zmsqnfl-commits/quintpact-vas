# Morrow 실제 웹앱 검증

VAS의 디자인·에이전트 인계가 실제 앱 구현으로 이어지는지 확인하기 위한 개인용 작업 보드다. 실행 화면은 `src/proof-app/index.html`이다.

## 요청부터 구현까지

1. `creative-board-request.json`의 요구사항으로 VAS 새 프로젝트 신청서 다섯 단계를 실제 입력했다.
2. Bento Studio를 선택하고 다운로드 버튼으로 `creative-board-handoff.json`을 저장했다.
3. 완료 화면의 복사 프롬프트를 `creative-board-handoff.txt`와 대조했다. 요청·전체 역할 본문·SHA-256 일치 검사를 통과했다.
4. 실제 하위 에이전트 `proof_designer`가 전체 인계를 읽고 화면 시안, 분리 그림, `creative-board-design.md`를 만들었다.
5. 실제 하위 에이전트 `proof_implementer`가 전체 구현자 지침·인계·디자인 명세를 읽고 앱 소스를 작성했다.
6. `proof_reviewer`에게 전체 검토자 지침과 수정 금지를 전달했다. 주 실행자는 테스트와 캡처를 확인하고 발견된 문제를 구현자에게 돌려보낸다.

호출 도구는 이름으로 등록된 VAS 네이티브 역할을 선택하는 방식이 아니다. 일반 하위 에이전트에 역할 본문·담당 파일·확정 토큰·완료 조건을 전달했다. 검토자는 호스트 권한을 상속하므로 별도 샌드박스라고 주장하지 않는다. 실제 호출 식별자·완료 상태·검토 전후 소스 해시와 최종 검사 결과는 `creative-board-results.json`에 기록한다.

## 앱 범위

- 작업 제목·메모·분류·상태·선택 마감일 추가/수정, 완료 전환.
- 제목과 메모 검색, 분류·상태 필터 조합과 초기화.
- 보관과 복원, 삭제와 실행 취소, 실제 현재 데이터의 JSON 내보내기.
- `morrow.board.v1`만 사용하는 브라우저 저장. 초기 네 작업은 예시라고 표시한다.
- 입력 검증, 빈 목록, 검색 결과 없음, 저장 차단·손상 안내와 원본 보존.
- 서버·계정·AI API 없는 앱이다. 기기 간 동기화와 JSON 가져오기는 이 검증의 범위에 포함하지 않았다.
- HTML/CSS/Vanilla JS는 이번 요청의 명시적 선택이다. 다른 VAS 대상 프로젝트의 기술 스택을 제한하지 않는다.

## 시안과 실제 화면 대조

| 항목 | 구현 기준과 확인 내용 |
| --- | --- |
| 구도 | 제목 두 열, 세로 그림 두 행, 라임 집중·검정 저장 타일, 전체 폭 작업 목록 |
| 문구 | 시안의 한국어 제목·행동·예시 작업을 실제 HTML로 구현 |
| 색상 | 인계의 배경·표면·주요 색상·본문·경계 토큰 사용. 그림 위 색상 덮개 없음 |
| 글자 | 로컬 Bricolage와 시스템 한글 폴백. 생성 시안보다 큰 차이가 나는 제목은 확정된 56px를 우선 |
| 간격 | 생성 이미지의 넓은 안쪽 여백 대신 확정 패딩·모서리 24px 적용 |
| 그림 | 시안에서 분리 생성한 그림만 이미지로 사용. UI 전체는 이미지로 붙이지 않음 |
| 기능 | 가짜 전체 선택 체크박스를 생략하고 완료 예시는 실제 체크 상태로 표시 |
| 모바일 | 1440/768/390/320px에서 줄바꿈·가로 넘침·입력 창과 버튼 조작 검사 |

첫 집중 검사에서 네이티브 dialog의 Tab 순환 누락을 발견해 명시적 포커스 순환을 추가했다. 저장 읽기 오류 안내에는 저장 실패와 원본 보존 사실을 함께 표시했다. 모바일 완료 체크 영역은 44px로 맞췄다.

## 재현

- 인계 다시 생성: `node scripts/build-proof-handoff.cjs` (새 실행의 인계 ID·해시로 검증 자료를 갱신하므로 기존 실행 기록과 구분한다).
- 앱 검사: `npm run test:browser -- tests/creative-board.spec.js --workers=2 --reporter=line --output <외부 결과 폴더>`.
- 전체 검사: `npm run test:python`, `npm run test:browser`, `npm run test:package`, `npm run agent:security`.
- 자동 브라우저 검사는 새 브라우저 컨텍스트를 사용한다. 사용자 브라우저의 기존 저장 공간을 지우지 않는다.
- 실험 결과는 이번 앱과 실행 호스트의 검증이다. 모든 코딩 도구·프로젝트에서 항상 같은 결과가 나온다는 보장은 아니다.
