## 화면의 목적과 구성

아이디어를 작업으로 추가하고 완료까지 관리하는 개인용 보드다. 모든 작업과 상태는 실제 로컬 데이터에 연결한다. 브랜딩용 소개 페이지나 가짜 통계판을 만들지 않는다.

큰 제목, 서로 다른 비율의 라임 작업 타일·검정 저장 타일·세로 그림 타일, 실제 작업 목록을 조합한다. 상단의 비대칭 타일은 Bento Studio의 정체성을 유지하고 하단은 검색과 편집이 빠른 목록으로 구성한다.

## 데스크톱 구조

- 전체 컨테이너는 최대 1360px, 가운데 정렬. 1440px에서 좌우 40px. 타일 간격 16px.
- 헤더는 높이 약 72px. 왼쪽 `morrow` 브랜드, 오른쪽 `작업 보드`와 `보관함` 전환. 현재 항목 아래 라임 선. 브랜드는 탐색을 방해하는 별도 장식 없음.
- 상단 그리드는 약 `1.15fr .9fr 1.15fr`. 제목은 첫 두 열, 그림은 마지막 열 두 행에 걸친다. 제목 최소 높이 330px, 아래 두 타일 약 220px. 고정 높이 대신 내용이 늘면 커지게 한다.
- 제목 문구는 `좋은 생각을,` / `끝낸 작업으로.` 두 줄. 그 아래 `만들고 싶은 것을 적고, 하나씩 완성하세요.`와 검정 `새 작업` 버튼. 앞의 더하기 아이콘은 실제 SVG.
- 라임 타일은 `지금 집중할 작업`, 현재 선택 작업의 분류와 예시 여부, 제목, `작업 열기`, 상태를 표시한다. 실제 진행 중 작업 우선, 없으면 미완료 작업을 사용한다. 작업이 없으면 `집중할 작업이 없어요.`와 `새 작업`을 표시한다.
- 검정 타일은 `이 브라우저에 저장`, 실제 저장 상태 설명, `JSON 내보내기` 버튼. 버튼은 표면색 경계·글자, 검정 배경이다.
- 오른쪽 그림은 `assets/morrow-print.png`. 타일 영역을 꽉 채우고 `object-fit:cover; object-position:center;`로 표시한다. 텍스트나 버튼을 이미지 위에 겹치지 않는다. 장식용 빈 alt를 사용한다.
- 하단의 큰 작업 패널은 모든 열을 차지한다. 제목 `모든 작업`, 검색 입력, 상태 필터와 분류 선택, 목록 순서다. 실제 결과가 0이면 빈 상태를 표시한다.
- 목록은 체크박스, 작업 제목, 분류, 상태, 예시 여부, 기한, 열기 버튼. 작업 제목은 길어도 줄바꿈한다. 메모는 편집 창에서 확인한다. 행 사이 얇은 경계만 사용하고 각 행에 새 카드를 두르지 않는다.
- 완료 체크박스는 상태를 실제 변경한다. 제목 또는 열기 버튼은 편집 창을 연다. 일반 글자와 필터는 일관된 크기로 유지한다.

## 편집과 기능 상태

- `새 작업`은 제목·메모·분류·상태·선택 마감일이 있는 네이티브 dialog를 연다. 편집 시 제목은 `작업 수정`. 저장 전의 입력은 취소하면 버린다.
- 창 너비는 최대 560px, 표면색, 24px 모서리·패딩. 헤더와 닫기, 제목 전체 폭, 메모 전체 폭, 분류·상태 두 열, 마감일, 행동 영역 순서. 화면 높이가 작으면 창 내부가 스크롤된다.
- 필드 레이블: `제목`, `메모`, `분류`, `상태`, `마감일 (선택)`. 행동: `취소`, `작업 추가` 또는 `변경 저장`. 편집 창에 `보관`, `삭제`를 구분해 배치한다.
- 제목은 공백만 허용하지 않는다. 오류는 입력 아래 `제목을 입력해 주세요.`와 `aria-invalid`로 연결하고 잘못된 필드에 포커스를 이동한다. 입력 오류 상태에서 창이 닫히거나 내용이 사라지지 않는다.
- 기본 입력은 표면색과 경계색. 포커스는 어두운 2px 외곽선 + 3px 간격. 검정 타일 안에서는 밝은 외곽선. 비활성은 설명과 disabled 속성, 눈에 보이는 흐린 상태를 함께 사용한다.
- 저장 성공은 실제 localStorage 쓰기가 끝난 뒤에만 표시한다. 실패하면 검정 저장 타일의 설명을 `브라우저에 저장하지 못했어요. JSON으로 보관해 주세요.`로 교체하고 명확한 상태 안내를 제공한다. 편집된 메모리 데이터는 유지해 내보낼 수 있게 한다.
- 검색은 제목과 메모를 함께 검색한다. 분류·상태 필터를 동시에 적용한다. 검색 결과가 없으면 `조건에 맞는 작업이 없어요.`와 `필터 초기화`. 완전히 빈 보드는 `첫 작업을 적어보세요.`와 `새 작업`.
- 보관은 작업 보드에서 숨기고 보관함에서 복원할 수 있게 한다. 삭제는 실행 취소 알림을 제공한다. 알림에는 실제 작업 제목과 `실행 취소`가 있고 키보드로 접근 가능해야 한다.
- dialog는 제목에 연결하고 포커스를 내부에 유지한다. Esc로 취소하고 닫히면 처음 연 버튼으로 복귀한다. 삭제 후 사라진 행의 포커스는 보드 제목이나 다음 논리적인 제어로 이동한다.
- 전역 알림은 작업 패널 아래 또는 화면 하단에 16px 여백을 둔다. 모바일에서 입력·저장 버튼을 덮지 않는다. 토스트만으로 저장 실패를 짧게 숨기지 않는다.
- 예시 데이터도 편집·완료·보관·삭제가 모두 가능하다. 사용자 입력은 textContent/안전한 DOM API로만 표시한다.
- 저장 키는 `morrow.board.v1` 하나다. 기존 VAS 설정이나 다른 앱의 키를 변경하지 않는다. JSON은 실제 현재 데이터로 내보낸다.

좁은 화면의 글자 축소는 확정 데스크톱 토큰을 보존한 반응형 규칙이다. 고정 폭 표를 수평 스크롤시키거나 중요한 작업 정보를 숨기지 않는다. 제목·메모·날짜의 긴 값은 컨테이너 안에서 줄바꿈한다. 버튼·탭·체크박스의 실제 터치 영역은 최소 44px다.

호버는 버튼 밝기 또는 1px 이동 정도, `.2s` 이내. 불필요한 반복 애니메이션은 없다. `prefers-reduced-motion: reduce`에서는 이동과 전환을 제거한다.

## 자산과 구현 인계

- 원본 그림의 배포 경로: `src/proof-app/assets/morrow-print.png`.
- 로컬 폰트: `src/assets/fonts/BricolageGrotesque.ttf`와 저장소의 라이선스 파일.
- 앱 기본 위치: `src/proof-app/`. HTML/CSS/Vanilla JS, 각 파일 500줄 이하.
- 이미지 생성 전체 화면은 검증 참고 자료다. 실제 UI 전체를 이미지로 붙이지 않는다. 브랜드·제목·목록·버튼·체크박스는 모두 실제 HTML.
- 아이콘은 20px, 2px 선, 둥근 끝의 SVG: 더하기, 검색, 열기, 닫기. 체크박스는 접근 가능한 네이티브 입력을 사용한다. 임의의 이모지 장식은 추가하지 않는다.

## 시안과 토큰의 우선순위 및 검증 계획

시안 생성 뒤 실제 인계 JSON을 다시 읽었다. 생성 이미지의 큰 제목이 56px보다 크고 몇몇 안쪽 간격도 24px보다 넓다. 구현은 확정 `fsHero:56px`, `padding:24px`를 우선한다. 화면의 구도·문구·색상 영역·그림은 시안을 따르되 이 두 값의 차이는 의도된 토큰 준수다. 이미지의 미세한 질감이 아닌 실제 CSS 색상은 확정된 단색 값을 사용한다.

생성 이미지에 표현된 전체 선택처럼 보이는 목록 머리 체크박스는 별도 일괄 기능이 요구되지 않았으므로 구현에서 생략한다. 완료 행의 체크 상태는 실제 데이터와 맞춘다. 상태표시와 표 머리 구조를 이 기능적 필요에 맞게 명시적으로 보완한다.

구현 검증자는 시안과 최신 브라우저 캡처를 각각 `view_image`로 열어 다음을 기록한다: 문구와 순서, 비대칭 상단 비율, 확정 글자 크기, 다섯 토큰 색상, 그림 크롭과 무색상 덮개, 24px 모서리·패딩, 모바일 줄바꿈. 이어 추가→수정→완료→검색/필터→보관/복원→삭제/실행 취소→새로고침 유지→JSON 내보내기→저장 오류를 확인한다. 이 문서는 그 검증이 이미 끝났다고 주장하지 않는다.
