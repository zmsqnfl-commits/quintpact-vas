# 운영 가이드

## 실행

- 일반 사용자: `Run-VAS-System.bat` 더블클릭
- 수동 실행: `powershell -ExecutionPolicy Bypass -File scripts/Start-VAS.ps1`
- 사용하지 않으면 로컬 서버는 기본 30분 뒤 종료됩니다.

VAS는 기존 프로그램의 폴더 위치만 프롬프트에 넣고 내부는 분석하지 않습니다. 실제 구조·기술 스택·실행 방법은 Codex·Claude·Antigravity가 원본 폴더에서 확인합니다.

기본 화면은 새 작업 지시를 만드는 데만 사용합니다. 결과 불러오기와 RAG 검토 모듈은 호환용으로만 보존합니다.

## 저장과 복구

- 코어 체크포인트: `.vas_backups/checkpoint_*.zip` 최신 10개
- Windows 작업 기억: `%LOCALAPPDATA%\QUINTPACT\VAS\`
- 브라우저 작업 기억: IndexedDB
- 작업 기억 가져오기: 브라우저와 Windows의 schema 1 형식을 지원하며 같은 ID는 병합합니다. 과거 Windows format/version 내보내기도 브라우저에서 읽습니다.
- 브라우저 기본 저장소의 기억 가져오기는 한 트랜잭션으로 확정합니다. 실패하면 기존 기록을 유지하고 같은 파일로 다시 시도할 수 있습니다. 외부 사용자 정의 어댑터는 자체 importData 구현의 원자성을 따라야 합니다.
- 기존 프로젝트·가져오기 자료: `workspace/`에 그대로 보존

## 개인정보

- 기본값은 작업 기억 사용 안 함입니다.
- 동의 전 이벤트를 기록하지 않습니다.
- 설정에서 사용·중지·삭제·전체 초기화를 언제든 실행할 수 있습니다.
- 비밀값, 파일 내용, 절대 경로, 파일명은 작업 기억에 저장하지 않습니다.
- JSON 항목 이름도 값과 같은 개인정보 검사를 거칩니다. 과거 기록은 내보낼 때 다시 정제하지만 기존 디스크 원본을 자동으로 지우지는 않습니다.
- 최종 JSON에는 연락처와 작업 기억 원본을 넣지 않습니다.
- 사용자가 고른 폴더 위치는 복사 프롬프트에만 사용하고 JSON·작업 기억·선택 기록 파일에는 저장하지 않습니다.
- 새 신청서 초안은 기본적으로 브라우저 localStorage에 저장되며 복원 버튼으로 불러옵니다. JSON 저장 뒤 삭제하지만 프롬프트 복사만으로는 삭제하지 않습니다. 작업 기억 동의와 별도인 현재 입력 복구 기능입니다.
- 기존 프로그램 화면의 현재 폴더 위치와 입력은 같은 탭의 history.state로 복구합니다. 공유하는 JSON에는 폴더 위치를 넣지 않습니다.
- 디자인 미리보기나 신청서 답변은 추천 기억으로 기록하지 않습니다. 동의한 경우 최종 복사·저장·디자인 적용 때 확정한 디자인만 기록합니다.
- 이전 버전의 확정 여부가 표시되지 않은 기록과 검색 기록은 새 디자인 추천에서 제외하며 원본 기록은 유지합니다.
- 영구 저장소 쓰기·삭제 실패는 성공으로 표시하지 않습니다. 브라우저 최초 저장소 초기화가 불가능하면 현재 화면의 임시 저장임을 표시합니다.
- 초안 자동 저장·설정 변경·삭제 실패는 화면에 표시합니다. JSON 다운로드 성공과 초안 삭제 실패는 각각 안내하며 삭제 버튼으로 재시도할 수 있습니다.
- 인증 헤더는 방식에 관계없이 전체 값과 접힌 후속 줄을 제외하고, URL authority의 사용자 정보도 제외합니다. 인증 헤더와 같은 줄에 이어 쓴 설명은 함께 제외될 수 있으므로 정상 요구사항은 다음 줄에 적습니다.
- 전체 초기화는 현재 화면·URL·열린 탭의 디자인과 추천도 기본값으로 되돌립니다.

## 검증

```powershell
npm.cmd run knowledge:check
npm.cmd run test:python
npm.cmd run test:browser
npm.cmd run test:package
```

`npm.cmd run test:release`의 10회 반복은 명시적 요청 때만 실행합니다.

## 배포

`npm.cmd run release:build` 후 `dist/SHA256SUMS.txt`와 ZIP의 `manifest.json`을 확인합니다. `.git`, `workspace`, 백업, 캐시, 환경 변수, 작업 기억은 배포에서 제외합니다.
