# VAS 2.7.4 AI 인계

새 프로젝트와 기존 프로그램 모두 같은 간단한 인계 흐름을 사용합니다.

```text
프롬프트 복사 → 코딩 AI에서 원본 확인 → 실제 작업
               └ VAS-AI-HANDOFF.json(v3)은 설정 보관이 필요할 때만 선택
```

## 사용

1. 기존 프로그램은 **폴더 위치**를 골라 복사 프롬프트에 포함합니다.
2. 새 프로젝트는 빈 폴더, 기존 프로그램은 프롬프트에 적힌 원본 폴더를 코딩 도구에서 엽니다.
3. VAS에서 복사한 프롬프트를 붙여넣습니다.
4. 설정 보관이 필요하면 `VAS-AI-HANDOFF.json`도 프로젝트 최상위에 저장합니다.
5. 참고 파일은 개수만 전달되며 이름과 내용은 포함하지 않습니다. 이미지·문서 원본은 코딩 AI에 별도로 첨부합니다.

복사 프롬프트에는 참고 URL, 대상 플랫폼, 기능·데이터 준비 상태, 일정·예산,
정확한 디자인 토큰과 Designer 스킬·Taste Profile 지침을 함께 넣습니다.
세부 토큰을 수정해도 원래 프리셋 방향은 유지합니다.
기본 디자인 예시는 편집·업무·운영·문서·소비자·제작 화면 구성으로 나뉩니다.
프로필 지침에는 구도, 글자 크기 비율, 간격, 반응형, 상태 확인 기준이 포함됩니다.
미리보기의 브랜드·문구·숫자·도형은 스타일 비교용이며 실제 프로젝트 데이터로 인계하지 않습니다.
브랜드 이름의 프리셋은 분위기 참고이며 해당 서비스의 화면을 그대로 복제하는 템플릿이 아닙니다.

## 에이전트 실행

주 실행자가 원본 확인·구현·검증을 책임집니다. UI 작업은 디자인 계획과 렌더링 비교를 포함합니다.
실제 하위 에이전트 도구가 있고 역할 분리가 유용할 때만 Designer·Reviewer에 작업을 맡기며 결과를 기다려 반영합니다.
도구가 없으면 같은 책임을 순서대로 수행하고, 실행하지 않은 에이전트나 검사를 실행했다고 보고하지 않습니다.

VAS 저장소에는 Codex용 `.codex/agents/vas_*.toml`과 Claude Code용 `.claude/agents/vas_*.md`가 있습니다.
이 설정은 해당 폴더를 연 호스트에서 사용하는 설정입니다. 다른 프로젝트에 프롬프트를 붙였다고 자동 설치되지 않습니다.
복사 프롬프트에는 도구에 종속되지 않는 작업 절차가 포함되므로 별도 설정 없이도 순차 작업이 가능합니다.
모델과 실행 권한은 현재 호스트 설정을 따릅니다. 이름으로 역할을 고르는 인자가 없으면 일반 하위 에이전트에 역할 지침 본문과 작업 범위를 직접 전달합니다.
복사 프롬프트에는 구현자·디자이너·검토자 지침이 포함되어 대상 프로젝트에 VAS 스킬 파일이 없어도 전달할 수 있습니다.
Reviewer의 네이티브 설정은 읽기 전용입니다. 일반 호출은 부모 권한을 상속할 수 있으므로 수정 금지를 명시하고 검토 전후 변경 여부를 확인합니다.

지침 원본은 `.agents/skills/`와 `.agents/HANDOFF-WORKFLOW.md`이며 `npm run agents:build`로 생성본을 갱신합니다.
개발 저장소에서 `npm run agent:verify`는 실제 Python·브라우저 검사를 실행하고 실패 코드를 반환합니다.
`npm run test:package` 후 `npm run agent:security`는 배포 경계·파일 목록·원본 해시를 검사합니다.
이 명령은 테스트 소스와 개발 의존성이 필요하며, 일반 실행 ZIP의 사용자 작업에는 요구하지 않습니다.
경로 검사 스크립트는 명시적 파일 쓰기의 사전 검사이며 호스트의 샌드박스나 모든 도구 호출을 대신하지 않습니다.
실제 호출·오류 수정·결과 회수의 확인 범위는 [에이전트 실행 검증](agent-runtime-validation.md)에 기록합니다.

## JSON 계약

- `workflow`: `handoffId`, 반복 번호, 이전 결과 연결
- `project`: 이름, 신규·기존 구분, 목표
- `task`: 요청, 제약, 완료 기준
- `context.requirements`: 사용자가 확인한 요구사항
- `context.design`: 프리셋, 토큰, 디자인 지침
- `context.rag`: 기본값은 비포함
- `context.continuation`: 기본값은 비포함
- `qualityGate`: 요구사항·디자인·RAG·개인정보 확인 상태
- `security`: 원본 불변과 제외 규칙
- `assistantGuide`: 코딩 도구에 붙여넣을 문장
- `integrity.payloadSha256`: 인계 내용 연결용 SHA-256

절대 경로, 비밀값, 연락처, 작업 기억 원본은 JSON에 포함하지 않습니다. 사용자가 고른 폴더 위치는 로컬에서 복사하는 프롬프트에만 포함합니다.
`analysis`와 파일 목록은 포함하지 않으며 실제 구조는 코딩 AI가 원본 폴더에서 확인합니다.

## 호환 계약

`VAS-AI-RESULT.json` 검증과 RAG 선택 모듈은 이전 데이터 호환을 위해 남아 있지만 일반 화면과 기본 프롬프트에는 표시하지 않습니다. 기본 저장·복사 동작도 반복 작업 영수증을 만들지 않습니다.

## RAG와 RBG

- RAG: 작업 기억은 사용자가 동의한 디자인 선택 추천에만 쓰며 기본 인계에는 넣지 않습니다.
- RBG: 코딩 AI가 생성 전에 원본 구조·규칙·진입점·검증 방법을 실제 파일에서 먼저 확인합니다.
