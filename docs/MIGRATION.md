# 업데이트와 마이그레이션 호환 정책

## 2.11.1 프로젝트형 ZIP으로 옮기기

2.11.1 Windows 배포본은 추출한 폴더 자체가 앱 프로젝트입니다. 최상위 `src/`는 앱 소스이고 `.vas/`는 VAS 도구입니다. 개발 저장소나 GitHub의 소스 ZIP은 이 배치가 아니므로 릴리스 자산의 `VAS-2.11.1-windows.zip`을 사용합니다.

1. 기존 VAS 실행을 종료하고 설치 폴더·실제 앱·사용자 파일을 백업합니다.
2. 새 ZIP을 **새 폴더**에 모두 풀고 첫 세션을 만들기 전에 최종 프로젝트 이름으로 바꿉니다. 기존 앱 위에 압축을 풀지 않습니다.
3. 기존 앱의 `src/`, 자산, 설정, 데이터와 `VAS-PROJECT-PROMPT.json`이 있으면 보존합니다. 실제 앱 소유 파일만 새 프로젝트로 옮기며 충돌하는 파일은 확인합니다. 이전 VAS 본체의 `src/`를 앱 소스로 복사하지 않습니다.
4. 기존 앱의 지침 파일을 일괄 덮어쓰지 않습니다. 새 시작 지침과 앱 고유 규칙을 함께 검토하고 필요한 내용을 유지합니다.
5. 새 폴더에서 새 대화를 열어 최신 프로젝트 지시와 실제 원본을 확인하고 작업을 연결합니다. 앱 실행과 지시 저장이 정상인지 확인할 때까지 이전 설치를 보관합니다.

프로젝트 지시는 앱과 함께 옮길 수 있지만 **PC 전용 세션·진행 요약·대상 연결은 자동 이전되지 않습니다**. 공개 설정이나 프로젝트 지시 파일만으로 개인 연결 기록을 복원할 수 없습니다. 이전 설치의 기록은 그 설치에서 확인하며 새 위치의 맥락은 실제 파일을 대조해 정리합니다. [설정 저장 안내](CHAT-STATE.md)를 참고하세요.

## 기존 인계와 호환 도구

원본 폴더를 코딩 도구에서 열고 프롬프트를 붙여넣는 기존 방식도 유지합니다. `VAS-AI-HANDOFF.json` 저장은 선택이며 기본 인계가 원본을 복사하거나 등록하지 않습니다.

이전 버전에서 만든 `workspace/projects/`와 백업·복제·검증·롤백 모듈은 데이터 호환을 위해 보존합니다. 기본 UI에는 노출하지 않지만 유지보수용 CLI와 인증된 로컬 호환 API로 사용할 수 있습니다.

```powershell
python scripts/vas-project-import.py --help
```

위 명령은 개발 저장소 기준입니다. 프로젝트 ZIP에서 호환 도구가 필요한 경우 `.vas/scripts/`의 같은 스크립트를 사용합니다.

호환 가져오기는 원본 실행 금지, 링크 차단, 백업 후 해시 검증 규칙을 유지합니다. 복구용 백업과 관리 복사본에는 원본 비밀값이 남을 수 있으며 공유용 파일이 아닙니다.

호환 내보내기는 임시 폴더의 JSON을 공통 정제기로 처리한 뒤 ZIP을 생성합니다. Python 또는 정제기가 없거나 파일이 손상되면 내보내기를 중단합니다. 디자인 색상과 일반 요구사항은 유지합니다.

프로젝트 지식 인덱스는 schema 3부터 사용합니다. 이전 인덱스는 검색·인계에 포함하지 않고 재생성이 필요함을 표시합니다. 재생성은 사용자가 호환 도구로 명시적으로 실행하며 기존 프로젝트를 자동으로 읽지 않습니다.

인코딩된 자격증명은 경로 치환 전에 제거합니다. 형식이 불명확한 연속 문자열·미완성 비밀값은 전체 입력을 제외할 수 있으므로, 정상 요구사항은 최종 인계에서 확인합니다.
