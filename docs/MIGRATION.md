# 마이그레이션 호환 정책

VAS의 기본 연결은 원본 폴더를 코딩 도구에서 열고 프롬프트를 붙여넣는 방식입니다. `VAS-AI-HANDOFF.json` 저장은 선택이며 VAS가 원본을 복사하거나 등록하지 않습니다.

이전 버전에서 만든 `workspace/projects/`와 백업·복제·검증·롤백 모듈은 데이터 호환을 위해 보존합니다. 기본 UI에는 노출하지 않지만 유지보수용 CLI와 인증된 로컬 호환 API로 사용할 수 있습니다.

```powershell
python scripts/vas-project-import.py --help
```

호환 가져오기는 원본 실행 금지, 링크 차단, 백업 후 해시 검증 규칙을 유지합니다. 복구용 백업과 관리 복사본에는 원본 비밀값이 남을 수 있으며 공유용 파일이 아닙니다.

호환 내보내기는 임시 폴더의 JSON을 공통 정제기로 처리한 뒤 ZIP을 생성합니다. Python 또는 정제기가 없거나 파일이 손상되면 내보내기를 중단합니다. 디자인 색상과 일반 요구사항은 유지합니다.

프로젝트 지식 인덱스는 schema 3부터 사용합니다. 이전 인덱스는 검색·인계에 포함하지 않고 재생성이 필요함을 표시합니다. 재생성은 사용자가 호환 도구로 명시적으로 실행하며 기존 프로젝트를 자동으로 읽지 않습니다.

인코딩된 자격증명은 경로 치환 전에 제거합니다. 형식이 불명확한 연속 문자열·미완성 비밀값은 전체 입력을 제외할 수 있으므로, 정상 요구사항은 최종 인계에서 확인합니다.
